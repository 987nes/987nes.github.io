## Session 2026-06-24 (refonte UX/design - NON pushe, en attente validation)

### Contexte
Retours utilisateur : typo "carree"/trop de polices, trop de tailles, boutons a clarifier/arrondir,
mascotte invisible sur mobile, mot "crypto" pas visible above-the-fold. Demande d'audit UX senior.

### Audit (chiffre sur le code)
- Space Mono utilise ~55x (boutons/nav/labels) vs Syne ~9x -> source du "carre"
- ~50 tailles de police distinctes sans echelle
- Boutons border-radius: 0
- Mascotte = background CSS ancre a droite -> hors-cadre sur mobile
- Hero n'affiche pas "crypto" sans scroll

### Changements (local, index.html)
1. **Design system** : :root + `--code` (mono technique), echelle `--fs-*`, `--radius`
   - 6 blocs techniques (ca-addr, wallet-addr, f-ca, htb-ca, news-proof, ticker) -> `--code`
   - Tout le reste du mono -> Syne (`--body`)
2. **Boutons** : border-radius (10px / 7px), Syne, poids 700-800, glow sur primaire
3. **Hero** : `<img class="hero-mascot">` (dzo-1.png) visible <=768px + bg retire sur mobile,
   tagline "A crypto token on Solana" (EN/FR/ES)
4. **Bloc Arcade** : nouvelle section #arcade (teaser jeu) -> game/index.html, lien nav "Arcade"

### Verifie (preview)
- Desktop + mobile OK, pas d'overflow horizontal, grille arcade 2 col, 0 erreur console
- Decision : garder single-page (pas de decomposition), jeu en page separee
